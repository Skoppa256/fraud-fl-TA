## Method that produced this, and what it cost

**Five phases**, each read-only-then-apply, each with a hard stop: A → A2 → B1 (§4.3) → B2 (BAB 1,
BAB 2, two document-wide fixes) → B3 (BAB 3).

**Every round overturned at least one confidently stated premise.** Across the whole programme:
the conda env, the enumeration figure, which scripts wrote into frozen trees, an exit code, the
provenance of `0,775`, a delta correction that was itself computed wrong, three "open" items that
were already closed, an entire blocking test built on the wrong instrument, and the belief that
BAB 1–3 was a fresh rewrite when 58 of 189 paragraphs matched at ≥ 0,90.

### Four techniques that earned their place

1. **Sweep for numerals and named concepts, not labels.** A document-wide `@`-reference scan
   returned all-clear on the dropped objects while four real dependencies sat in prose as bare
   numbers. Typst warns about none of them, and a dangling reference renders as `?` with a clean
   compile.
2. **The verbatim token proof.** Strip markup, compare paragraph by paragraph and token by token
   against the source, and require every differing run to be an authorized deviation. In B2 this
   caught six object blocks grabbed by line range that had pulled stray old prose into BAB 2 —
   the compile passed with zero warnings and the PDF looked correct.
3. **Derive object blocks by walking back from the label to the opening `#figure(`, asserting on
   both the first and the last line.** Never by line range. This is what (2) found.
4. **Read the rendered PDF, not the source.** A phantom chapter from a hard-wrapped `=`, a
   duplicated sentence, a broken table layout and an English "Section 4.3" were each caught this
   way and by nothing else.

### Three standing rules

In `docs/rq3_method_notes.md`:

1. *When a result is unusually clean, derive what the number would be if the code were wrong. If
   the answer is "the same", the number is not evidence.*
2. *No code path may substitute stand-in data, skip work, or swallow an error and still report
   success. Missing or empty input must fail loudly, naming the path it looked in.*
3. *A record of open items decays. Re-verify each against the file before acting on it.*

### Governing constraints, unchanged

- **"You do not commit. I do."**
- Never resolve a numeric disagreement by picking the more plausible value. When a full-precision
  rule and an instruction conflicted, the rule correctly beat the instruction.
- The author's typographic slips are preserved deliberately — `darititik-titik`, `masing- masing`,
  `pohon- pohon`, `aktual,dengan`, `terdeteksi,tetapi`, `Implemetasi`, `Explanaible`, `ektrem`,
  `memilki`, `instirusi`. A silent repair is how a "verbatim" claim stops being true; that
